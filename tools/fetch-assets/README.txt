qtclient-fetch-assets
=====================

Copies game assets from your local official CipSoft Tibia install into
data/assets and data/sounds next to this helper (or --out DIR).

  1. Install Tibia from tibia.com
  2. ./qtclient-fetch-assets
     # or: ./qtclient-fetch-assets --tibia /path/to/Tibia.app
  3. ./client

No CIP blobs are downloaded or redistributed — BYO licensed install only.
